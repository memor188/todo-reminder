# 代办软件制作

一个待办事项（To-Do）软件的从零实现记录。

## 当前状态

**仓库刚建立，代码尚未开始写。** 技术栈待定。

## 技术栈（待定）

| 候选 | 优点 | 代价 |
| --- | --- | --- |
| 纯网页（HTML/CSS/JS + localStorage） | 零部署成本，双击就能跑，数据存浏览器 | 换设备不同步 |
| 网页 + 云服务 | 多设备同步，可上线分享 | 要接后端，多一层复杂度 |
| Python 桌面端 | 复用已有的 Python 基础 | 打包分发麻烦 |

## 仓库约定

- 默认分支：`main`
- 提交信息加类型前缀：`feat` / `fix` / `docs` / `refactor` / `chore`
- 依赖、虚拟环境、`.env` 一律不入库（见 `.gitignore`）
- 一个功能一个提交，别攒成一坨
